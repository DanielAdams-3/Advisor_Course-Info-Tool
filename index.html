Course Info Retrieval Tool-CIRT

About CIRT

An internal advisor-facing tool to retrieve course information for graduate courses. Data is pre-collected, so information is not 'live'.

Search by Course Number

About Course Search

Requires a full course number (aka subject code). For example, to get course information about 'CSCI 5214 Big Data Architecture', type CSCI5214, CSCI-5214, or CSCI 5214. If you do not know the full number, use autocomplete tab. For Special Topics courses, use the Special Topics Search tab.

Enter a course number (for ex: CSCI 5253) and click Search

Get Suggestions - AutoComplete

Enter the first letter(s) of a course subject code (ex: A, ATLS, ATLS-5) and click AutoComplete to retrieve suggestions.

About AutoComplete

Must start with beginning of subject code. All available results will match those characters.
